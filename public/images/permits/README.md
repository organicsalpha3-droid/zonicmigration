# Zonic Migration — Genuine Work Permit Images Directory

Place your 5–6 genuine client work permit scans in this directory.

### Replacement Guide
1. Before publishing genuine documents, permanently redact:
   - Full names and personal signatures
   - Photos / facial portraits
   - Passport numbers and QID/Emirates ID/BRP reference numbers
   - Dates of birth and personal residence addresses
   - QR codes and Barcodes
2. Save your redacted files as JPG, PNG, or WebP:
   - `permit-sample-1.jpg` (or `.png` / `.webp`)
   - `permit-sample-2.jpg`
   - `permit-sample-3.jpg`
   - `permit-sample-4.jpg`
   - `permit-sample-5.jpg`
   - `permit-sample-6.jpg`
3. Update `permitSamples` in `src/config/site.ts` to point to the file names if you change extensions.
